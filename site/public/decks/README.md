# Decks

Published presentations live here, one folder per deck, each a self-contained
`index.html` copied by `node scripts/deck/build.mjs publish <slug>` from a deck in `decks/`,
without its speaker notes, and only when the owner asked for that deck to be public. A deck at
`site/public/decks/pitch/index.html` is live at `https://<domain>/decks/pitch/`.

How to build one: `source/formats/deck.md`.
