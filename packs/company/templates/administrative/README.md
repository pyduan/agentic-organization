# administrative

People, addresses, accounts, HR topics.

- `people/`: one file per person, plus `emails.md`.
- `accounts.md`: service accounts, who holds them, what they cost.
- `hr.md`: contracts, pay, what is open.
- `images/people/`: the photos shown on the intranet.

This repo is private, but "private" means "visible to the whole organization". A national ID number,
bank details or a scan of an identity document do not go in a git repo, even a private one.
