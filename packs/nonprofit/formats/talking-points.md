# Talking points

`<fundersPath>/TALKING-POINTS.md`: the current answers the organization gives about itself to
funders, each with the metric it uses and its source. It exists because the same question ("how many
people did you reach?") has several true answers that measure different things, and a funder who
hears two of them without the definitions reads one as inflated.

```markdown
# Talking points, as of 2026-10-29

## How many people

| Metric | Value | Counts | Does not count | Source | Use with |
|---|---|---|---|---|---|
| People reached | 48,000 | anyone who received at least one message since launch | whether they read it | source/content/programme-figures.md | public pages, general audiences |
| Active users | 9,100 | people with two or more sessions in the last 90 days | | analytics export of 2026-10-01 | funders asking about engagement |

## What changed since the last version

- 2026-10-29 · active users redefined from 30 to 90 days, so the October figure is not comparable with July's
```

## Rules

- One row per metric, never one row per number: the definition is the content.
- A value comes from `source/content/` or `source/facts/` with its date, never from memory or from a
  previous report.
- When a definition changes, the change gets a dated line, and every funder whose figures table
  used the old definition is named in it.
